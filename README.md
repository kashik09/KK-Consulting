## Overview of the Project
The web application of the consulting agency - KK-Consulting offers users an easy and efficient experience. The development was done by using HTML, CSS, and JavaScript to offer a structured, nice-looking, fully functional user experience.

## Features
**Semantic HTML Structure**: The code uses `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` elements to provide greater accessibility and search engine optimization.
- **Multi-Page Layout**: Consists of `index.html` for Home, `about.html` for About, and `contact.html` for Contact for full navigation.
- **Responsive Design**: Responsive for desktop, tablet, and mobile devices by the use of CSS media queries.
- **JavaScript Interactivity**: DOM manipulation and event handling were used to give more life to the application.
- **Form Handling and Validation**: Contact form working with JavaScript form validation integrated with `localStorage`.
- **Data Persistence**: Supports saving and fetching user inputs across multiple pages using localStorage.
- **Error Handling**: Indicates user errors for invalid form field entries with responsive messages.

## Technologies Used
- **HTML5**: Semantic content with an organized structure.
- **CSS3**: Used Flexbox, Grid, and media queries for responsiveness to achieve visual harmony.
- **JavaScript (ES6+)**: For interactivity, form validation, and data storage capabilities.

## Usage
Navigate through Home, About and Contact pages using the site menu.
 Fill out and submit the contact form to witness a few of the built in validation features.
 Pull and show form data that is stored using localStorage.
